# Low-Level Design Study Plan (Hello Interview)

## The loop

```
/lld-pretest <topic>  →  read it on Hello Interview  →  /lld-drill <topic>
        ↑                                                    │
        └──── /lld-drill review (spaced repetition) ◄────────┘
```

After the core concepts, practice problem breakdowns with `/lld-drill <problem>` (e.g. `parking-lot`).

## Files
- `curriculum.md`: topics and the testable points the skills quiz on
- `progress.md`: status, scores, review schedule
- `notes/<topic>.md`: gaps and interview-ready lines per topic
- `cards/<topic>.md`: flashcards in your own words; `python3 lld/space_sync.py [slug]` syncs them to Space ("LLD · <Topic>" decks)
- `sources/`: PDFs of pages you've pulled in. Gitignored: paid content stays local and never gets pushed.

Grading uses the shared scale in `../system-design/levels.md`; spoken mode uses `../system-design/spoken-mode.md`.
